# FormIQ Labs

A static storefront and learning-portal prototype for affordable, hands-on engineering kits. Each featured project is designed around one engineering fundamental and a multi-week, guided build from scratch.

## Preview

Open `index.html` in a browser. No build step or package installation is required.

## Featured kits

- **Room Sentinel** — motion sensing, camera integration, and a visible local entry alert.
- **Maglev Control Lab** — magnetism, position sensing, and feedback control.
- **Hydraulic Arm** — fluid pressure, actuation, and mechanical linkages.

The preview prices are illustrative targets under £40, before delivery.

## Prototype features

- Searchable, filterable kit catalog with product details and a demo cart.
- Contributor form for adding a kit, including a foundation-video link.
- Demo student portal with a kit-specific project chat.
- Separate `logo-ideas.html` page with visual logo concepts.

## Prototype limitations

Login, kit uploads, cart, and chat are browser-local demos; they are not connected to a backend. The site does not process payments, host videos, or generate printable QR codes. Before launch, connect real authentication, storage, checkout, video destinations, and QR generation.
